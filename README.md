# Onebit Adventure (Projeto Educacional)

Este é um projeto desenvolvido como parte da disciplina de **Programação de Jogos**, com o objetivo de aprender e aplicar conceitos básicos de desenvolvimento de jogos.  
Este projeto é uma **recriação educacional** do jogo *Onebit Adventure* e não tem como objetivo final a distribuição ou uso comercial.

## 📖 Sobre o Projeto

O foco deste projeto foi **aprender programação** utilizando conceitos como:
- Manipulação de sprites e animações.
- Controle de eventos e input do usuário.
- Sistema de colisão.
- Criação de inimigos, obstáculos e power-ups.
- Estruturação de cenas e fases.

> **Atenção**: Este projeto é apenas para fins de estudo e **não possui autorização oficial** dos criadores do jogo *Onebit Adventure*. Caso você seja um dos autores e deseje a remoção do conteúdo, por favor entre em contato.

## 🛠️ Tecnologias Utilizadas

- Linguagem: c++
- Motor de jogo: O motor do jogo utilizado para desenvolvimento é de autoria do meu professor de programção de jogos https://www.youtube.com/watch?v=EuQyOyN6keA&list=PLX6Nyaq0ebfjfo4PlkAcKRxR66qXZk899
- Ferramentas: Visual Studio Community

## 🚀 Como Executar

1. Clone o repositório:
   
git clone https://github.com/seu_usuario/onebit-adventure-clone.git
cd onebit-adventure-clone

2. Abra o projeto no Visual Studio Community:
   
No Visual Studio, clique em "Open Project" e selecione o diretório do projeto clonado.
 Verifique se todas as dependências estão corretamente configuradas.

3. Configure o ambiente:

Certifique-se de que o C++ Desktop Development está instalado no Visual Studio.

4. Compilar o projeto:

No Visual Studio, selecione Build > Build Solution ou pressione Ctrl + Shift + B.

5. Executar o projeto:
   
Após a compilação bem-sucedida, clique em Run (F5) para executar o jogo.

7. Problemas comuns:
   
Se houver erros na compilação do projeto, uma possível causa pode ser os seus Drivers!
Tente atualizar os seus drivers de vídeo, verifique se vocÊ tem o directX11 instalado.
